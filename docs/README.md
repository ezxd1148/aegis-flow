# Documentation README

This directory contains documentation for the Aegis Flow project.

Aegis Flow is a Microservice security & Vulnerability Scanner. Its field focus is on Cybersecurity, Static/Dynamic Code Analysis and Container Security.

Aegis Flow is an automated dashboard tool that plugs into GitHub/GitLab repositories to scan Dockerfiles, dependency trees (SBOM generation), and source code for secrets or known vulnerabilities which is CVEs while generating reports and patch PRs.

Tech Stack: Go, Zig, Docker API, Github Actions/Webhooks, PostgreSQL, Trivy/Grype open source engine integrations, Next.js w/ Tailwind CSS for Dashboard UI/UX(Recharts/Tremor for rendering CVE trend lines).
